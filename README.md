# Smart Campus Sports Analytics

A web application for collecting and analysing college sports performance records.

## Features

- Student profiles
- Sports performance recording
- Performance history
- Interactive dashboards
- Data visualization
- Machine learning prediction
- Model evaluation
- CSV import and export

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- SQLite
- Git and GitHub

## Installation

Install the required libraries:

    python -m pip install -r requirements.txt

Run the application:

    python -m streamlit run app.py

## Development Versions

V1 - Basic application and database

V2 - Student management

V3 - Data analytics

V4 - Machine learning

V5 - Model evaluation

V6 - Complete dashboard and reports

## Privacy

Use college-approved data and anonymised records for public demonstrations.
Do not upload private student records to GitHub.
